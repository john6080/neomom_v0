Project with three parts: 
 
	two GUI's using python and pyinstaller, one engine using fortran ifx / gfortran.
	
Components:

	neomom_input, Python exe
	neomom, fortran engine, ifx/gfortran
	neomom_plot, Python exe

Develop on Ubuntu and Windows

	Ubuntu:  vs code for GUI's and engine ifx/gfortran

	Windows: vscode for GUI's, Visual Studio for fortran ifx engine.

Goal:  

	One directory structure suitable for long term.  
	Ability to upload to Git Hub.
	one place for Windows and Linux distributable packages for ziping.
