neomom_input

Build the geometry, set run parameters, and launch the solver. Walkthrough: a 10 m center-fed dipole, 10 m above ground.

1
Give the run a name — this becomes the title on your pattern plots later.
2
Set Start and Stop to the same value for a single-frequency run, and leave Mode on Pattern Sweep (use VNA Sweep instead if you want an impedance-vs-frequency sweep for neomom_Zin).
3
Pick a ground model. Real ground needs Epsilon (dielectric constant) and Sigma (conductivity, S/m); typical soil values shown.
4
Set mesh density and turn on Output Currents if you want to inspect current distribution in neomom_current afterward.
5
With Launch plot: Yes, neomom_plot opens automatically with your results as soon as the solver finishes.

5 · Save and run

File menu

Run Solver…
1
Save the geometry as an .nml file.
2
Validate checks the model for obvious problems (unconnected nodes, missing feed, etc.) before you spend solve time on it.
3
Run Solver… launches the neomom engine on this file directly — no need to open a terminal. With Launch plot set to Yes on the Globals tab, neomom_plot opens automatically when it's done.
Tip: use View → Show Preview Window at any point to see a 3D rendering of the geometry you've built so far, before running the solver.
