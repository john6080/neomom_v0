3 · Pick a visualization mode

Five modes are available. 3D – Standard gives the full 3D lobe; 2D – Azimuth/Elevation give classic polar cuts; Top-Down is a bird's-eye compass view; Map Overlay plots the footprint on a real map, centered on a lat/lon you provide.

Pick which field component(s) to show — Etotal is the usual choice; Ev/Eh isolate vertical/horizontal polarization.
2
Surface shading and the color/ring scale — ARRL matches the classic ARRL Antenna Book ring convention if that's what you're used to reading.
3
Each mode opens its own independent plot window — you can have several open side by side to compare, for example, elevation and 3D views at once.

5 · Optional — compare against NEC5

Antenna Pattern Viewer — Sources
1
☑ NeoMoM (solid)
1
☑ NEC5 (dashed)
1
Once both a NeoMoM CSV and a NEC5 .out are loaded (step 1), check both Sources boxes. 2D plots then overlay NeoMoM as solid color-coded lines with NEC5 as black dot markers, each independently normalized to its own peak gain so the comparison isn't skewed by the two engines' different internal field-scale conventions.
Bottom bar: Close All Plots clears every open plot window at once — handy once you've opened several while comparing modes.
