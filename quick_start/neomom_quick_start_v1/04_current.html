neomom_current

Window title: NeoMoM Current Viewer. Needs a .cur file — only produced when Output Currents was set to Yes in neomom_input.

1 · Open a file

NeoMoM Current Viewer — toolbar
1
Open…No file loaded
1
Click Open… (or File → Open .cur file…) and select the .cur file from your solver run.

2 · Three views, one per tab

NeoMoM Current Viewer
3D |I|
3D Phase
2D Plot
3D wire geometry, colored by current magnitude along its length
1
3D |I| — the wire geometry in 3D, color-coded by current magnitude, so you can see at a glance where the current is concentrated.
2
3D Phase — same geometry, colored by current phase instead of magnitude.
3
2D Plot — current and impedance plotted against arc-length, one trace per wire — see below.

1
If the default Zin y-axis range clips your data, set new min/max and click Redraw Zin.
2
Check this box to switch the x-axis from physical arc-length to electrical length in wavelengths — often more useful for comparing wires of different physical lengths at the same frequency.
