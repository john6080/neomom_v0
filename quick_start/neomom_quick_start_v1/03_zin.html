neomom_Zin

Window title: NeoMoM — Impedance Sweep Viewer. Needs a frequency sweep, not a single-frequency pattern run.

Before you get here: back in neomom_input's Globals tab, the Mode must be set to VNA Sweep (not Pattern Sweep) with a Step size, so the solver produces an impedance-vs-frequency file across the band rather than one radiation pattern at a single frequency.

1 · Import a sweep

1
Click Import file… (or File → Open / Import…) and pick the VNA-sweep CSV.
2
Each imported file appears in the Datasets list on the left. Import more than one to overlay several sweeps on the same plot — useful for comparing design variants, or comparing model against a real antenna analyzer measurement. Clear all resets the list.

2 · Pick a view

NeoMoM — Impedance Sweep Viewer — toolbar
1

2

3
Z₀ [Ω]50
1
Three tabs across the top of the plot: R / X (resistance/reactance vs frequency), G / B (conductance/susceptance), and SWR.
2
Ham Bands overlays shaded amateur band edges on the plot, so you can see at a glance where your sweep crosses into or out of a band.
3
On the SWR tab, set Z₀ to your feedline's characteristic impedance (50 Ω is the usual default) — SWR is computed relative to this reference.
