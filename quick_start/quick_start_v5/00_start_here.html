NeoMoM Quick Start

A four-part antenna simulation suite: build a geometry, run the solver, and view the results.

Install

Each release zip contains all five programs together in one folder — the solver engine plus the four viewer/editor apps — along with a models/ folder of example antennas.

Linux

1
Unzip neomom_linux.zip to wherever you want the suite to live, e.g. ~/bin/neomom.
2
Mark the five programs executable — on Linux they have no file extension:
cd ~/bin/neomom
chmod +x neomom neomom_input neomom_plot neomom_Zin neomom_current
3
Add the folder to your PATH so you can launch any of them by name from a terminal:
echo 'export PATH="$HOME/bin/neomom:$PATH"' >> ~/.bashrc
source ~/.bashrc
4
Verify it worked — this should pop open the geometry editor window:
neomom_input

Windows

1
Unzip neomom_windows.zip to wherever you want the suite to live, e.g. C:\Users\<you>\neomom.
2
No chmod step needed — Windows .exe files are already runnable as-is.
3
Double-click any of the five .exe files directly from Explorer, or pin shortcuts to the Start menu / taskbar. To launch them by name from a Command Prompt instead, add the folder to your PATH: System Properties → Environment Variables → Path → New, then paste the folder path.
4
Verify it worked by double-clicking neomom_input.exe.
What's what: neomom is the Fortran solver engine — it has no window; it runs from the command line (or is launched for you by neomom_input). The other four are the GUIs covered in this guide.
