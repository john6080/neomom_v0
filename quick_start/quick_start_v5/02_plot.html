neomom_plot

Window title: Antenna Pattern Viewer. View a radiation pattern, optionally alongside a NEC5 comparison.

Top to bottom: Input Files · Antenna info · Visualization Mode · Options · Close All Plots
1
Input Files — if neomom_input launched this for you automatically (Launch plot: Yes), the CSV is already loaded, as shown here. Otherwise Browse… to the pattern CSV your solver run produced. A NEC5 .out file can be loaded alongside it for comparison — see step 5.
2
Antenna — reflects the metadata header from the loaded file: a quick sanity check that you loaded the run you meant to, at the frequency you expected.
3
Visualization Mode — five modes: 2D – Azimuth/Elevation for classic polar cuts, 3D – Standard for the full 3D lobe, 3D – Top-Down for a bird's-eye compass view, and Map Overlay for the footprint plotted on a real map.
4
Options — this panel changes to match the selected mode. Shown here for 2D – Azimuth: pick field Components (Etotal is the usual choice), a color/ring Scale, and a cut angle, then click the Plot button. Each mode opens its own independent plot window, so you can have several open side by side.

Angle cuts — Azimuth and Elevation are single slices

Each 2D – Azimuth or 2D – Elevation plot is one slice through the full 3D pattern, not the whole thing:

  • Azimuth cut sweeps phi (compass direction) around, at one fixed theta (elevation angle) you set with the theta = control.
  • Elevation cut sweeps theta (elevation angle) up and down, at one fixed phi (compass direction) you set with the phi = control.

A different cut angle is a genuinely different plot, not a cosmetic change — for a directional antenna, an azimuth cut taken at theta = 90° (the horizon) and one taken at theta = 30° can look completely different, and neither one by itself represents the whole pattern. If you need the full picture rather than one slice, use 3D – Standard, or step through a few different cut angles on the 2D views to build up a mental model of how the pattern changes with elevation (or azimuth).

Field components — Ev, Eh, Etotal

At every far-field direction (theta, phi), the radiated E-field has no component along the line-of-sight (radial) direction — it's purely transverse, and splits into two orthogonal directions: θ̂ (theta-hat, the elevation direction) and φ̂ (phi-hat, the azimuth direction).

ComponentDefinitionMeaning
Ev|E_theta| — magnitude along θ̂ (Utheta)"Vertical" polarization — the co-polar component for a vertically-oriented antenna
Eh|E_phi| — magnitude along φ̂ (Uphi)"Horizontal" polarization — the co-polar component for a horizontally-oriented antenna
Etotalsqrt(Ev² + Eh²)Total radiated field magnitude, independent of how it splits between the two polarizations

Which to plot depends on what you're checking: Etotal for overall radiated power and gain regardless of polarization; Ev and Eh separately when polarization purity matters — for example, checking how much of a nominally-vertical antenna's field is actually leaking into the horizontal component off-axis.

Amplitude scales — Linear, dB peak, dBi, ARRL

ScaleWhat it showsReference point
LinearField magnitude normalized 0–1 against the pattern's own peakRelative to that plot only — no physical units
dB peakdB relative to the pattern's own peak (peak = 0 dB)Relative to that plot only — no physical units
dBiAbsolute gain in dBi, anchored to the solver's computed peak gain for this runTrue antenna gain — meaningful on its own and comparable across different runs
ARRLSame idea as dB peak, floored at −40 dB and mapped through the ARRL Antenna Book's nonlinear ring spacing (0, −3, −10, −20, −30, −40 dB rings)Relative to that plot only, but matches the classic printed ARRL-style pattern plots

Worth keeping straight: Linear, dB peak, and ARRL are all renormalized to that particular plot's own peak — two different antennas, or two different runs of the same antenna, will each fill the outer ring even if their actual gain is very different. dBi is the one scale anchored to a real physical reference (isotropic radiator), so it's the one to use when comparing gain across separate runs or designs side by side.
