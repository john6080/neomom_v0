neomom_current

Window title: NeoMoM Current Viewer. Needs a .cur file — only produced when Output Currents was set to Yes in neomom_input.

Toolbar (Open… / Zin axis controls) above the tabs: 3D |I| · 3D Phase · 2D Plot
1
Open… (or File → Open .cur file…) loads the .cur file from your solver run.
2
3D |I| (shown here) — the wire geometry in 3D, color-coded by current magnitude, so you can see at a glance where the current is concentrated: brightest at the center feed, tapering toward the open ends, exactly as expected for a center-fed dipole.
3
3D Phase — same geometry, colored by current phase instead of magnitude.
4
2D Plot — current and impedance plotted against arc-length, one trace per wire.

☐ Scale x-axis by wavelength (λ)
1
If the default Zin y-axis range clips your data, set new min/max and click Redraw Zin.
2
Check this box to switch the x-axis from physical arc-length to electrical length in wavelengths — often more useful for comparing wires of different physical lengths at the same frequency.
Note: the 2D Plot controls above are shown as a wireframe — that tab only builds its toolbar once you switch to it, after a file is already loaded.

Export

File → Save all plots as PNG… exports every open tab's plot as a PNG in one step, into a folder you choose.
