neomom_plot

Window title: Antenna Pattern Viewer. View a radiation pattern, optionally alongside a NEC5 comparison.

Top to bottom: Input Files · Antenna info · Visualization Mode · Options · Close All Plots
1
Input Files — if neomom_input launched this for you automatically (Launch plot: Yes), the CSV is already loaded, as shown here. Otherwise Browse… to the pattern CSV your solver run produced. A NEC5 .out file can be loaded alongside it for comparison — see step 5.
2
Antenna — reflects the metadata header from the loaded file: a quick sanity check that you loaded the run you meant to, at the frequency you expected.
3
Visualization Mode — five modes: 2D – Azimuth/Elevation for classic polar cuts, 3D – Standard for the full 3D lobe, 3D – Top-Down for a bird's-eye compass view, and Map Overlay for the footprint plotted on a real map.
4
Options — this panel changes to match the selected mode. Shown here for 2D – Azimuth: pick field Components (Etotal is the usual choice), a color/ring Scale, and a cut angle, then click the Plot button. Each mode opens its own independent plot window, so you can have several open side by side.

5 · Optional — compare against NEC5

Once both a NeoMoM CSV and a NEC5 .out are loaded, check both Sources boxes. 2D plots then overlay NeoMoM as solid color-coded lines with NEC5 as black dot markers, each independently normalized to its own peak gain so the comparison isn't skewed by the two engines' different internal field-scale conventions.
Note: the Sources box above is a wireframe rather than a screenshot — it only appears once a NEC5 .out file is loaded, which needs the optional nec_out_reader.py module (not present in the environment used to capture these screenshots, so the app correctly disabled that feature — see the message under Input Files in the real screenshot above).
