neomom_input

Build the geometry, set run parameters, and launch the solver. Walkthrough: a 10 m center-fed dipole, 10 m above ground.

1 · Globals tab

Boxes top to bottom: Run Title · Frequency · Ground · Solver Options · Run Controls
1
Run Title — give the run a name; this becomes the title on your pattern plots later.
2
Frequency — set Start and Stop to the same value for a single-frequency run, and leave Mode on Pattern Sweep (use VNA Sweep instead for an impedance-vs-frequency sweep to use in neomom_Zin).
3
Ground — pick a ground model. Real ground needs Epsilon (dielectric constant) and Sigma (conductivity, S/m); typical soil values shown.
4
Solver Options — set mesh density and turn on Output Currents if you want to inspect current distribution in neomom_current afterward.
5
Run Controls — with Launch plot set to Yes, neomom_plot opens automatically with your results as soon as the solver finishes.

2 · Nodes tab — place the wire endpoints

Table top, entry row + Units/Z Height above it, Add/Apply/Delete below
1
Confirm Units is set to Meters (the coordinates here assume meters).
2
Fill in the Tag/X/Y/Z row and click Add three times to place: N1 (-5, 0, 10), N2 (0, 0, 10) — the feed point at center — and N3 (5, 0, 10). This lays the dipole along the X axis, 10 m above ground.
3
Click a row in the table to load it into the entry fields; edit and Apply, or select and Delete to remove it.

3 · Wires tab — connect the nodes

The AWG gauge reference table (shown here) opens automatically whenever this tab is active
1
Tag / Node Tags — name the wire and list the node tags it passes through in order: N1 → N2 → N3 strings the whole dipole together through the center feed point in one wire.
2
Radius — set the wire radius in meters, or click Gauge Table… to look up a radius by AWG wire size instead of converting by hand. This reference table pops up automatically the moment you land on this tab.
3
Click Add to create the wire.

4 · Excitations tab — add the feed

Wire Tag / Node Tag / Voltage / Phase entry, Add/Apply/Delete below
1
Wire Tag / Node Tag — point the feed at the wire and the specific node on it: here, W1 at node N2, the dipole's center.
2
Voltage / Phase — a simple single feed uses Voltage 1.0, Phase 0.
3
Click Add to place the feed.

5 · Geometry preview

Opens automatically at startup; View → Show Preview Window brings it back if closed
1
Blue dots and labels are your nodes (N1/N2/N3); the black line is the wire; the red marker is the feed point at N2; the green plane is the ground.
2
Use this to sanity-check your geometry — a wire in the wrong place or a feed on the wrong node is much easier to spot here than in the tables.

6 · Save and run

File menu
1
Save As NML…
2
Validate
3
Run Solver…
1
Save the geometry as an .nml file.
2
Validate checks the model for obvious problems (unconnected nodes, missing feed, etc.) before you spend solve time on it.
3
Run Solver… launches the neomom engine on this file directly — no need to open a terminal. With Launch plot set to Yes on the Globals tab, neomom_plot opens automatically when it's done.
Note: the menu above is shown as a wireframe, not a screenshot — a real Tk menu bar can't be captured meaningfully as a static image since it only renders when clicked open.
